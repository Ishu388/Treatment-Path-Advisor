# TreatmentPath Advisor

TreatmentPath Advisor is a local-first educational healthcare decision-support project. Its React interface calls a local FastAPI service, which uses a scikit-learn Decision Tree and local SQLite storage. It is not a diagnostic or treatment-prescribing system.

## Features

- Patient registration and login, patient and doctor dashboards, and an admin dashboard.
- Symptom assessment with 38 binary features, three ranked predictions, confidence, a prediction-specific decision path, and global feature importance.
- Rule-based emergency warnings, educational care pathways, self-care information, precautions, and clinician-consultation warnings.
- English and Tamil language selections; translation coverage is partial and some text remains English.
- Prediction history, PDF report generation, document vault, emergency request/chat flows, notifications, reminders, feedback, and admin charts.
- Nearby doctor/hospital views. Hospital lookup uses OpenStreetMap; provider listings are not fabricated. Map tiles and live lookup require internet and are optional.

The current frontend does not provide a persistent dark/light theme toggle, Care Circle, or Export Center.

## Technology Stack

- Backend API: Python, FastAPI, Uvicorn, Pydantic.
- Machine learning: scikit-learn `DecisionTreeClassifier`, Joblib, NumPy, pandas.
- Persistence: local SQLite.
- Frontend: React 18, Vite, React Router, Chart.js, Leaflet.

The current `npm audit` reports two transitive advisories in the Vite/esbuild development toolchain. npm only offers a forced Vite 8 major upgrade as a fix; that breaking upgrade was not applied without a compatibility pass.

## System Architecture

```text
React/Vite (5173) -> FastAPI (8012) -> local Decision Tree + SQLite
                                      -> local treatment knowledge base
```

FastAPI is the complete backend used by the React workflows. Vite forwards `/api` requests to it during development. When `frontend/dist` exists, FastAPI also serves the production React app and assets from the same origin. Port 8011 was occupied by a pre-existing process, so this project now uses 8012 and no longer depends on that process.

## Machine Learning Workflow

The FastAPI service uses the same model and feature-column artifacts generated by `model/train_model.py`. The model accepts 38 binary symptom features and predicts 13 educational categories, all of which have entries in `treatment_kb.py`. The pipeline reads `data/symptom_dataset.csv`, performs a stratified 80/20 train/test split, calculates held-out metrics, and fits the saved serving model on the full dataset. Dataset generation is deterministic.

## Running Backend

From the repository root:

```powershell
python app.py
```

Or run Uvicorn directly:

```powershell
cd backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8012 --reload
```

The API listens on `127.0.0.1:8012` by default. `PORT` overrides the port; `TREATMENTPATH_RELOAD=1` enables reload when using `python app.py`.

## Running Frontend

For development, in another terminal:

```powershell
cd frontend
npm run dev
```

Open the Vite URL, normally `http://127.0.0.1:5173`. For production, run `npm run build` and open `http://127.0.0.1:8012` while the backend is running.

## API Endpoints

- `GET /model-info`: model configuration and held-out evaluation metrics.
- `POST /predict`: compatibility endpoint for symptom assessment.
- `POST /api/treatment-path`: primary React assessment endpoint.
- `GET /api/ml-insights`: model insights, decision tree, confusion matrix, and global feature importance.
- Additional `/api` routes provide authentication, profiles, history, reports, emergency workflows, nearby lookup, documents, reminders, notifications, and admin/doctor views.

Request validation rejects empty symptom lists, unknown names, unsupported severity values, invalid duration types, and malformed JSON with JSON errors. The prediction response contains top predictions, confidence, the actual model decision path, global feature importance, risk status, and the mapped local care guidance.

## Model Information

The model is a Decision Tree with entropy criterion, maximum depth 10, and random state 42. It has 38 inputs and 13 output classes. Severity is validated and used by risk rules; it is not an ML feature.

Regenerated held-out metrics from the checked-in dataset: accuracy 75.32%, weighted precision 78.00%, weighted recall 75.32%, and weighted F1 75.78% (312 test examples). These are project-dataset results, not clinical validation.

Regenerate the serving model, feature columns, and metrics from the repository root:

```powershell
python -m model.train_model
```

This updates `treatment_model.joblib`, `symptom_columns.joblib`, and `model_metrics.json`, including the confusion matrix and test-split metadata.

## Explainability

- **Decision path** lists the actual Decision Tree splits traversed for that input.
- **Feature importance** describes global model importance; it is not a patient-specific attribution.

## Emergency Alert

Chest pain, shortness of breath, difficulty breathing, severe weakness, severe model risk, and configured critical vital-sign thresholds trigger an emergency warning before normal educational guidance. Users are told to seek immediate professional assistance. Model results are not diagnoses and must not delay emergency care.

## English/Tamil Support

The language selector and translation catalogs support English and Tamil, but coverage is partial: many page labels and backend-generated text remain English. Language preference is stored in browser local storage.

## Privacy

The SQLite database is `backend/app.db`. It stores users (passwords are hashed), patient profiles, assessments, emergency requests/chats, feedback, reminders, provider records supplied locally, condition catalog, translations, notifications, and document metadata. Tables include `predictions`, `users`, `patients`, `emergency_requests`, `emergency_chats`, `feedback`, `reminders`, `doctors`, `hospitals`, `condition_catalog`, `translations`, `notifications`, and `documents`. Uploaded files live under `backend/uploads`.

The app does not encrypt local database or upload files; protect the machine and manage backups/deletion deliberately. Browser local storage contains session/profile data, language preference, and emergency contact information. Nearby hospital lookup sends coordinates to OpenStreetMap's Overpass service when used.

## Offline Capability

Local prediction, model inference, educational treatment guidance, authentication, and SQLite storage work without internet. Map tiles and marker assets use external OpenStreetMap/CDN hosts, hospital lookup uses Overpass, and external directions open Google Maps; those location features are optional and require internet. No cloud inference, external medical API, or AI prediction API is used. The interface uses local system fonts.

## Medical Disclaimer

This academic system uses synthetic/project data and has not been clinically validated. It does not diagnose, prescribe, or replace a licensed healthcare professional. Seek immediate professional help for emergencies.
